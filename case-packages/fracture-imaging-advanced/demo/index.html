成像测井裂缝与孔洞智能解释

像素学习 → 对象检测 → 密度、产状与标定开度估计

纯前端训练/推断 · 合成标定模型 · 直井圆筒假设
01 / PROBLEM

裂缝、孔洞与干扰：为什么必须联合解释？

井壁展开图以方位为横轴、深度为纵轴。天然平面裂缝在直井的理想展开图中形成正弦轨迹，孔洞形成局部区域；层理、诱导缝和噪声也能产生相似响应。它们分别关系到储集空间、流动通道与井周应力解释，误判会影响储层评价。

本例模拟3条天然裂缝、3个孔洞、2条宽层理带及一对纵向诱导缝干扰。仅天然裂缝和孔洞为检测目标；真实天然/诱导成因不能只凭形状断定。显示灰度是合成响应，不等同于特定电成像或声成像仪器的完整物理响应。

02 / INTERVENTION

像素学习 + 几何约束，形成对象级成果

两个逻辑回归分类器分别学习裂缝、孔洞分数，输入暗度及水平/垂直的近远邻域对比。采用4幅几何不同的合成训练图；每个分类器均衡使用600个正样本与600个负样本，少数类必要时重采样。

裂缝：参数搜索与加权最小二乘拟合正弦轨迹，按周向支持率与残差筛选并去重。孔洞：周期连通域、形态过滤、邻近碎片合并，并排除与已拟合裂缝重叠的碎片。整个对象提取过程不读取测试真值。不是U-Net，不将模型分数称为已校准概率。

03 / DATA

数据与标定：每个专业量都要有依据

  • 图像与标签：裂缝、孔洞掩膜及干扰类型；真实项目按井分组验证。
  • 方位：0°在左端，向右顺时针，0°/360°周期相接；需仪器北向标定。
  • 深度：本例1000.000–1000.600 m，240个采样行；间隔为井段长度/239。
  • 井径：默认216 mm，直井、圆形井筒假设；井斜与井径变化会影响产状换算。
  • 开度标定：本例已知纵向高斯模糊σ=0.65像素；真实灰度图无法单独保证实际开度解释。

测试图与训练图裂缝几何不同。测试标签只用于最终评估和参考轮廓；指标对应同一幅合成测试图，不代表独立工区泛化。孔洞面积比是二维井壁图像面积比，不是三维储层孔隙度。

04 / DIFFICULTY

高难度场景：计算边界与质量控制

难点包括细小目标、类别不均衡、相似形态、断续轨迹和标定误差。像素IoU只衡量位置重叠；对象匹配、拟合残差与周向支持率共同评价裂缝解释。

直井几何：拟合 z=z₀+a·sinθ+b·cosθ，振幅A=√(a²+b²)；倾角δ=atan(2A/D)，最大深度方位作为倾向，走向按倾向+90°取0–180°。P10=检出裂缝条数/井段长度，仅为交切频度，不是体积裂缝密度。

开度输出为本合成标定模型下的估计：沿深度测得FWHM，扣除已知成像模糊，再乘cosδ换算平面法向宽度。低于模糊分辨限显示“不可分辨”；真实电成像需电学响应/充填与仪器标定，声成像也需相应标定，不能把图上像素宽度直接当作真实裂缝开度。

参考：IODP井壁成像 · SLB成像解释功能 · 计算机视觉方法。真实数据扩展方向：U-Net分割、天然/诱导缝多类鉴别、缺失扇区与井斜校正。

从像素到专业解释的完整链条

1. 几何与数据标定

深度、方位、井径、仪器分辨率

输入像素对应物理尺度；直井假设明确。

2. 双目标像素学习

4幅训练图、独立测试图、5种局部特征

生成裂缝与孔洞分数；不接触测试标签。

3. 对象检测与去干扰

正弦候选搜索、连通域、形态筛选与碎片合并

输出轨迹和孔洞区域；纵向干扰不计入天然裂缝条数。

4. 专业参数计算

从拟合轨迹、对象面积与标定值计算

裂缝条数/P10、倾角/倾向/走向、开度估计、孔洞面积与等效直径。

5. 分层验证与复核

像素IoU、对象匹配、几何误差、参考叠加

展示误检和漏检；所有结果可导出并回查。
DUAL-TARGET DETECTION / GEOMETRY / VALIDATION

检测到哪里，还要解释是什么、多少、什么方向

绿色：天然裂缝候选；紫色：孔洞候选。灰度图含宽层理及成对纵向干扰，模型先学习，几何与形态规则再筛选。

智能方法如何起作用逻辑回归像素分类 + 正弦轨迹拟合 + 孔洞连通域分析 · 展开原理与验证步骤
为什么有效

分类器从合成训练图像学习局部对比度等特征，生成裂缝与孔洞分数；几何和形态筛选将碎片像素组织成对象，减少层理等干扰。

怎样操作验证

先点“弱目标实验”，调整像素阈值与轨迹支持率，比较三幅图、像素 IoU 和对象误检漏检；再查看裂缝产状与孔洞尺寸。

适用边界：阈值过低会增加误检，过高会漏掉弱目标。本示范不是 CNN；宽度估计依赖已知模糊标定，不能直接用于真实工区。

标定参数、开度公式与训练信息

只调整标定不会改变像素检测，专业量将按新比例重算。倾角=atan(2×轨迹振幅×深度间隔/井径)。开度估计=√(FWHM²−(2.355×0.65)²)×深度间隔×cos(倾角)，长度统一为mm；0.65像素为本合成图像已知模糊σ。低于分辨限则不输出开度。真实场景必须另行标定。

孔洞等效直径由二维展开面积计算；面积比不是三维孔隙度。P10为条/m，不进行井眼取向偏差校正。天然/诱导标签仅为形态模拟，不声称完成真实成因鉴别。

全部图像和参考参数为合成数据。检测、拟合与尺寸计算不使用测试标签；参考值仅用于验证。需真实井资料、成像仪器与岩心验证后才能用于工程解释。
