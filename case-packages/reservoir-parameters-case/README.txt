测井-储层参数智能解释 · 完整教学实现2.0.2

独立查看：解压后打开demo/index.html。首次会在浏览器实际训练两套小型神经网络。
导入：老师主页“添加案例”，拖入整个reservoir-parameters-case文件夹，选择“测井 / 储层参数智能解释”，校验并添加。建议先移除旧KNN版，以免同场景出现两个案例切换。

实现：4→16→12→3多层感知机、tanh隐藏层、手写反向传播与Adam；普通监督MLP、物理边界+训练试油约束MLP、KNN三者对比。
数据：6训练井（每井6–24个稀疏标定点）+2验证井+1测试井。仅训练标定点参与标准化；只用训练井30个层段的合成试油参考作联合损失。测试井101点和5个试油层段只用于评价。
演示：孔隙度/渗透率/含水饱和度；噪声、标定点数、深度错配、训练轮次、试油权重可调；曲线、散点、损失、岩心样点、独立井误差、试油代理条形图和JSON导出。
物理边界：phi、Sw在0–1内；渗透率0.01–1000mD为本合成区块先验，不是通用物理定律。lambda=0关闭试油损失但保留输出边界。
试油：简化径向达西代理，固定20m层厚、2MPa压差、3mPa·s黏度、200m外半径、0.1m井半径，相对渗透率因子(1-Sw)^2；不作真实现场产量预测。
验证：16组训练设置、物理范围、指标独立计算、深度错配的参考不变性、流量单位关系、两种网络反向传播有限差分、交互逻辑与主页导入校验通过。尚未完成真实浏览器视觉和拖拽验收。
全部数据均为合成；按井分离不代表真实跨区泛化。网络和约束未必优于KNN。

2.0.1复核：训练试油参考与岩心数量的随机抽样解耦；同井同深度标签噪声可复现；lambda=0仍评估试油误差但不加入梯度；KNN补齐同验证井评价。
