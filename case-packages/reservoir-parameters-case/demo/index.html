01 / PROBLEM

岩石能装多少、流得多快、其中有多少水？

储层评价需要同时理解孔隙度、渗透率和含水饱和度：孔隙多不代表连通好，连通好也不意味着孔隙中一定有油。测井曲线是物理响应，不能单凭一条曲线给出完整储层结论。

传统解释常借助经验关系与岩心标定。面对不同岩性、泥质含量及流体条件，多条曲线的关系可能交叠，需要联合分析。

本例把岩心稀疏、深度归位误差和试油验证串联起来，不只画出预测曲线。孔隙度与含水饱和度标签来自模拟岩心/实验解释；渗透率在log10(k / 1mD)尺度建模。

02 / INTERVENTION

深度回归、物理边界和试油约束如何结合？

实际训练一个4→16→12→3多层感知机，两个隐藏层用tanh；4条输入为GR、DEN、CNL、logRT，3个输出为孔隙度、log渗透率、含水饱和度。反向传播与Adam更新均在浏览器中执行。

普通网络仅使用稀疏岩心监督；约束网络采用有界输出，并在监督损失上加入训练井的层段试油参考损失。φ与Sw限制在0–1，渗透率在本合成区块先验0.01–1000mD内；这一区间不是适用于所有油田的普遍物理定律。KNN仍作为对照。

训练目标：岩心监督误差 + λ×训练层段log流量误差 + 小幅权重正则。独立测试试油参考不参与损失。对照包含输出映射与联合损失两项改变，不能把全部效果单独归因于某一种约束。

03 / DATA

按井分离：训练、验证与最终测试

  • 训练：6口合成井，每井6–24个稀疏标定点，默认72点；同时提供30个训练层段的合成试油参考。
  • 验证：另外2口合成井，仅展示独立误差，不反向传播，也不按测试结果选择训练轮次。
  • 测试：另1口合成井，101个深度点；5个20m层段的试油参考仅用于最终验证。
  • 标准化：均值和标准差只由训练标定点计算，测试曲线不参与拟合。
  • 错配实验：把岩心标签配到偏移深度的测井输入，模拟归位错误；不是偷偷改变参考真值。

所有井都来自同一套简化合成机制，井间分离不等于已证明真实跨区泛化。常规曲线单位、实验标签单位及来源须保留；真实数据还需井径、泥浆侵入、仪器与实验条件质控。

实验控制：改变标定点数不会改变同一训练井的试油参考；普通MLP、约束MLP与KNN均在相同验证井和测试井上评价。λ=0时仍计算并显示训练试油误差，但不把它加入更新梯度。

04 / DIFFICULTY

独立层段验证：物性不能直接等于产量

试油部分使用带相对渗透率因子的简化径向达西代理：q=2πkhΔp/[μln(re/rw)]×(1−Sw)²。固定Δp=2MPa、μ=3mPa·s、re=200m、rw=0.1m，层厚20m，单位转换后输出m³/d；不包含皮肤、体积系数、复杂多相与非均质井筒耦合。

训练/测试参考流量均由各自隐藏物性场与独立测量扰动合成。模型只读取对应测井特征；测试参考没有反向输入模型。合成试油验证展示物性组合与流动能力的一致性，不能视为真实油井产能预测或生产保证。

MAE、RMSE、R²分别报告，φ和Sw误差为百分点pp，渗透率误差为dex。网络可能不如KNN，加入约束也不保证每项误差下降。参考方向：深度回归、物理约束学习、迁移学习；本例未把跨区微调实现成按钮。

从稀疏岩心标定到连续参数与试油验证

目标是把多条测井曲线转换为可验证的储层参数解释：不仅预测φ、k和Sw，还要说明标签怎样准备、网络怎样学习、约束怎样加入，以及如何在独立井上检查结果。

以下五步与当前演示中的数据、模型和指标逐项对应。合成数据允许演练完整流程，但不替代真实工区验证。

STEP 01 / 数据工程

样点准备、深度归位与按井划分

输入：6口训练井的测井曲线、稀疏岩心/实验标签，另有2口验证井和1口测试井。

具体操作：检查曲线单位、采样间隔与缺失；将标定标签配到相同深度的测井特征。按井分离训练、验证与测试；错配实验将标签配到偏移0–4m的位置。

预期输出：形成训练标定点及明确的井级分组；默认每口训练井12点，共72点。
易错点：不能将同井相邻深度随机拆分后宣称跨井效果；归位错误会把正确标签对应到错误曲线。
STEP 02 / 特征工程

特征构造与训练集标准化

输入：GR、DEN、CNL、RT四条曲线，以及训练点的三个参数标签。

具体操作：对RT取log10；仅从训练标定点计算各通道均值与标准差，并用同一参数处理验证与测试。渗透率标签转换为log10(k / 1mD)并缩放参与训练。

预期输出：得到尺度可比较的4维输入，保存标准化参数供所有模型共用。
易错点：不能用测试数据估计均值与标准差；孔隙度和饱和度的小数、百分数不能混用。
STEP 03 / 算法核心

多层神经网络学习与岩心监督

输入：标准化训练特征及对应的孔隙度、渗透率、含水饱和度标定值。

具体操作：训练4→16→12→3网络，隐藏层用tanh，反向传播计算梯度，Adam更新权重。监督损失对三个归一化输出计算误差，并对孔隙度加权；普通网络与约束网络使用相同训练点。

预期输出：获得能够从测井特征预测三个物性参数的模型；记录实际训练损失曲线。
易错点：训练损失下降不代表独立井误差一定下降；网络可能不如KNN。训练轮次可调，但测试参考不能进入梯度。
STEP 04 / 约束与对比

物理先验与训练试油联合约束

输入：稀疏监督标签、训练井30个20m层段的合成试油参考，以及固定流动条件。

具体操作：约束网络通过有界输出限制φ、Sw在0–1内，采用本示范区块渗透率先验0.01–1000mD。每个训练层段取5个代表位置预测物性，代入简化达西代理并加入log流量误差；前30轮逐步引入权重λ。

预期输出：形成岩心监督与试油一致性联合训练；对照普通MLP与KNN。λ=0关闭试油梯度，但仍显示试油误差。
易错点：试油约束使用训练井参考，不能拿测试试油调训练权重后声称盲测。代理忽略皮肤等因素，约束本身也可能引入偏差。
STEP 05 / 验证与交付

连续预测、独立层段验证与人工复核

输入：训练完成的三个模型、2口验证井、1口测试井，以及5个独立测试层段参考。

具体操作：沿测试井101个深度点预测三个参数，计算MAE、RMSE、R²；在相同验证井上评价三种模型。将测试层段预测物性转换为流动代理，与独立合成试油参考比较，并检查物理越界。

预期输出：输出连续参数剖面、散点图、模型误差表、层段试油对比及JSON结果；定位应复核的深度和层段。
易错点：测试井参考不参与模型训练。二维图表好看不等于地质解释正确；真实应用仍需岩心、试油、井况与专业人员复核。

评价口径与交付结果

孔隙度和Sw误差以百分点pp报告；渗透率以dex报告，并在逐深度读数中转换回mD。R²允许为负。试油代理采用固定压差、黏度、井半径与层厚，比较单位统一为m³/d。

测试参考 vs 预测

训练设置与试油代理的适用范围

约束网络输出φ、Sw∈[0,1]；渗透率采用本示范区块先验0.01–1000mD。λ=0只关闭试油损失，输出边界仍保留。训练试油误差仍会计算用于评估，不参与梯度更新。测试试油未参与训练。

试油代理：q=2πkhΔp/[μln(re/rw)]×(1−Sw)²；h=20m，Δp=2MPa、μ=3mPa·s、re=200m、rw=0.1m，k按mD换算后输出m³/d。忽略皮肤、体积系数及复杂多相，仅用于合成教学约束，不作现场产量预测。

全部为合成数据，按井分离仍不能证明真实跨区泛化。神经网络不保证胜过KNN，约束也不保证所有独立指标改善。
