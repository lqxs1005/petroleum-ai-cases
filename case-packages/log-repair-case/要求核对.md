# 测井数据修复：要求核对

- 石油背景：GR缺失、异常尖峰、井径异常影响及下游解释风险。
- 智能化方法：掩码滑动窗口MLP，融合DEN/CNL/logRT及前后GR邻点；中心GR不输入。
- 异常判断：按六种输入状态的验证RMSE归一化残差，结合井径记录，明确异常分数并非概率。
- 重建与对照：同一掩码下神经重建与插值，正常点保留，边界采用端点延拓。
- 专业背景：4段正文与概念、掩码、分井、评价图解。
- 案例流程：5步，包含输入、操作、输出、易错点与图解。
- 案例演示：主曲线、缺口与异常标记、六状态误差带、阈值分数图、深度联动、辅助曲线、训练曲线、独立评价、下游泥质指数代理、分页记录、JSON导出。
- 数据隔离：4训练井804点，1验证井201点，1测试井201点；全部合成。
- 评价：缺失段、实际受损点（含漏检）、全部修复点（含误报）；TP/FP/FN、MAE/RMSE。
- 无输入情形：低依据估计明确标记，不声称可靠恢复。
- 兼容：纯前端、离线资源、case.json契约、sandbox隔离；通过原主站添加案例的多文件导入与实际运行检查。
- 验证：162组参数、反向传播差分、独立NumPy对照1206点、结构与资源检查；Chrome结果切换及高度变化、长缺口联动、五案例徽标/校验检查。

## 范围

本案例重建GR一个目标通道，用辅助曲线和序列窗口体现修复要点。未实现实测文件分析、全部通道修复、真实跨区泛化；这些不作为本教学演示的完成声明。

本说明仅覆盖第5个案例；整个课程作业还需网站发布链接、讲解视频、亮点文档及结课报告。
