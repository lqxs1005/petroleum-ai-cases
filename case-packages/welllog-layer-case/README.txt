测井-测井曲线智能分层

1. 独立查看：打开 demo/index.html，三个标签均可使用；无需安装、无需联网。
2. 导入老师主页：先解压本包，在老师主页点击“＋ 添加案例”，将整个 welllog-layer-case 文件夹拖入；确认场景为“测井 / 测井曲线智能分层”，校验并添加。不要只拖入HTML或只拖case.json。
3. 三个部分：专业背景、案例流程、案例演示；流程页每一步有本次计算的中间结果。
4. 演示：调整噪声、切换惩罚、薄层厚度、K值；查看参考层与预测层、界面匹配、F1；CSV导出依浏览器下载权限。
5. 算法：K-means学习曲线响应簇，动态规划加入切换惩罚。无外部依赖、无后端、无预训练深度网络。
6. 数据：固定种子合成数据，不是实测井；所有指标由当前输出计算，不代表工区性能。
7. 原主页上传案例通常保存在当前浏览器；最终发布整站时需要把案例永久集成到源代码，不能只依靠浏览器上传状态。

版本1.0.1：导入主页时自动隐藏演示页内部的重复导航和大标题；单独打开仍保留三个完整标签。
