01 / CONTEXT

从曲线读懂地下地层

测井仪沿井筒记录不同深度的岩石响应。自然伽马 GR 常用于辅助识别泥质含量；体积密度 DEN 与岩石骨架和孔隙有关；电阻率 RT 同时受岩性、孔隙流体和矿化度影响。单条曲线不能直接等同于岩性或含油性。

传统解释需要同时对照多条曲线、岩心与邻井。薄层、噪声和渐变过渡容易造成解释差异。

业务价值：将整段曲线的逐点浏览转为候选界面复核，为后续储层参数解释、射孔选段与压裂分段提供参考。分层结果不直接等于含油结论；本例不提供未经实测的节省工时数字。

02 / METHOD

智能方法介入在哪里

本例以无监督 K-means 学习多曲线的响应类型，再使用带切换惩罚的动态规划求解深度序列的类别路径。目标函数为 Σ‖标准化曲线−类别中心‖² + λ×切换次数。λ 越大，分层越平滑，但越容易漏掉薄层。

这是可实际计算的机器学习简化示范，不声称运行了深度神经网络。类别编号只是响应簇，不自动代表地质层名；最终需地质人员结合岩心及邻井确认。

03 / DATA

数据与标注怎样准备

输入：带深度和单位的 GR、DEN、RT 曲线；检查采样间隔、缺失值、井径异常与深度一致性。电阻率先取 log10，再按训练段均值与标准差标准化。

演示使用固定种子的合成井，深度 1000–1100 m、间隔 0.5 m。参考地层用于评估，不参与聚类和分段。实际项目应按井划分训练与验证，避免邻近深度泄漏；样本量需按区块差异与标签质量评估。

  • ☐ 曲线：深度、GR(API)、DEN(g/cm³)、RT(Ω·m)，保留单位和采样间隔。
  • ☐ 质控：记录缺失、井径扩大、异常跳变和深度校正。
  • ☐ 标注：演示聚类无须标签；评价需要独立的参考层界和解释标准。
  • ☐ 规模：本例201点；真实项目可先用数口完整井验证流程，再增加独立井评估跨井差异，规模需按工区确定。
  • ☐ 验证：按井分组，保存训练标准化参数及模型版本。
04 / EVALUATION

怎样判断有效，哪里会失效

按深度顺序最优一对一匹配候选界面和参考界面（优先最大命中数，再最小总误差），深度差不超过 1 m 记为命中。精确率＝命中/预测界面数，召回率＝命中/参考界面数，F1 为两者调和平均。界面平均误差只统计匹配成功的界面，必须同时看召回率。

局限：合成岩性响应较理想，真实井受泥浆侵入、井径扩大、流体与区域差异影响。不要把本演示的数值当作真实工区精度。参考方向：变点检测、隐马尔可夫模型、1D CNN 序列分割。

技术难度：中。算法可在浏览器运行，但薄层识别、井况干扰和跨井迁移需要额外验证。

方法入口：变点检测 / 序列分割 / 1D卷积网络（时序方法）。
